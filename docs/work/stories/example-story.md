# Example story

> Throwaway. Delete along with [[example-epic]] once you've written a real
> one.

**What it is.** Shows what a filled-in story looks like — small enough
that you could sit down and finish it, and specific enough that you'd know
when you had.

**Why it matters.** A story that can't be finished in one go is really an
epic wearing a disguise. If the "Done when" list below runs past four or
five items, split it.

## Done when

- The file has a status, an epic, and a name that says what it does.
- Its epic lists it back under `## Stories`.

## Notes

`blocked-by` is left empty above. When something genuinely blocks this,
put `blocked-by: "[[other-story]]"` there — that's what draws the line
between them in the graph.
