## Acceptance criteria

Each line is something you could check by using the site — true or false,
no judgment call. Cover the happy path, then the edge cases and error
states that would embarrass you if they were missing.

- Happy path: the normal case works end to end.
- Edge case: an unusual but real input or sequence is handled on purpose,
  not by accident.
- Error state: something goes wrong (bad input, network failure,
  permission denied) and the person sees something sensible, not a
  broken screen.
